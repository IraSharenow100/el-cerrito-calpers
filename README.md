# El Cerrito CalPERS UAL Analysis

This project provides a comprehensive analysis of the City of El Cerrito’s Unfunded Accrued Liability (UAL) with CalPERS. The analysis includes interactive tables and charts built using R, financial data processing in Excel, and a formatted final report in Word. It is intended for use by policymakers and the public,.

## 🔍 Project Objective

To assess the scope and implications of El Cerrito's CalPERS pension debt, using publicly available data and a combination of R, Excel, and Word-based reporting. The report covers key assumptions, historical funding trends, and projected UAL payments.

## 📁 Included Files

| File Name | Description |
|-----------|-------------|
| **El Cerrito CalPERS Excel Project.xlsx** | Source workbook with pivot tables and raw data, organized by CalPERS plan and funding type. |
| **El Cerrito CalPERS UAL Analysis.Rmd** | R Markdown file used to clean data, create visualizations, and generate the final report. |
| **El-Cerrito-CalPERS-UAL-Analysis.docx** | Final formatted Word report with embedded tables and charts. |

## 📊 Highlights

Key outputs from the project include:

- A summary of El Cerrito’s total UAL by plan.
- A comparison of projected UAL payments.
- Charts showing funding ratios, retiree ratios, support ratios, and more.
